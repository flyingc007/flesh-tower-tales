# 肉身塔传说 · 制作总控

## 触发条件

任何与《肉身塔为什么不开门》项目相关的内容生成任务均触发：分镜脚本执行、角色/场景图像生成、视频生成、资产取用与复用。用户只要提到该项目名、角色名（状元/王灵官/地藏/金乔觉）、场景名（肉身宝殿/五溪桥/仙境显圣）或分镜/镜头，即进入本流程。

## 触发保障（重要）

本 skill 依靠 description 中的关键词触发。为稳定接管，**向用户产出提示词或执行生成时，提醒用户：生成请求尽量带上项目/角色/场景关键词**（如"生成状元在五溪桥被鞭的镜头，按项目总纲定位资产"）。若用户表述完全不含关键词（如只说"生成一个穿袈裟的僧人镜头"），本 skill 可能不触发，此时应主动补问是否属于肉身塔项目，确认后按本流程执行，避免退回凭记忆取材。

## 强制前置：读项目总纲（唯一设定基准）

无论任务具体是什么，**第一步必须完整读取**：

```
{{PROJECT_ROOT}}\00_项目总纲.md
```

总纲是唯一设定基准，含：故事红线（严禁违反）、角色资产清单、场景资产清单、角色形态区分规则、版本记录。任何创作、修改、生成均以此为准，禁止设定漂移。

## 核心流程

### 第 1 步：读总纲
完整读取 `00_项目总纲.md`。若总纲内容与用户表述冲突，**以总纲为准**；如需偏离总纲，先向用户确认并更新总纲版本号。

### 第 2 步：定位资产
按总纲角色/场景清单，从本地项目目录定位锚定图：

```
{{PROJECT_ROOT}}\03_图像资产\
  ├── 人物\状元\...
  ├── 人物\地藏_肉身塔内\...
  ├── 人物\地藏_显圣版\...
  ├── 人物\王灵官_显圣版\...
  ├── 人物\群演\...
  └── 场景\...
```

实际取用时，用文件系统工具列出对应子目录，读取用户当前涉及的角色的锚定图作为生成输入。目录不存在或缺失时，如实报告缺失项，不凭空假设路径。

**清单一致性检查（强制）**：定位资产时，对照 `03_图像资产\资产清单.md` 与实际文件夹，若发现不一致（文件夹有但清单未登记 / 清单登记但文件夹缺失 / 状态、锚点、v 号不符），**向用户报告差异并提示更新清单**，不得静默跳过。原则：资产清单与文件夹必须一致，改文件夹必同步改清单。

### 第 3 步：应用角色锁定协议
涉及任何角色复用/图生/图生视频时，**必须读取并应用** character-reference-lock skill：

```
{{SKILL_ROOT}}\character-reference-lock
```

先 Read 其 SKILL.md，再按其中契约锁定角色、拼接强约束提示词与负面词。

### 第 4 步：执行角色形态区分（红线，极易出错）
按总纲第五节严格执行，两种形态**不可混用**：
- **肉身塔内（状元锥刺）**：金乔觉不坏肉身真身（坐化安坐、深红袈裟、禅定印、垂目禅定相）。
- **仙境对话（地藏与王灵官）**：地藏显圣法身（云海莲台、锡杖托珠、金环光、真人感、**睁眼**；以睁眼布局图为基准，禁止闭眼）。

生成前先确认镜头处于哪个空间，再选定形态。错用形态必须纠正。

## 红线清单（严禁违反，生成时逐项检查）

1. 严格忠于原著，不擅自增删剧情、不新增原著没有的对白与桥段。
2. 状元是主动不信神佛、前来验证灵验的负面角色。
3. 塔内锥刺的是金乔觉不坏肉身真身（非泥塑、非显圣法身）。
4. 地藏嘱咐"过了五里桥就算了"，王灵官误听成五溪桥，在五溪桥打死状元。
5. 王灵官被罚驻守塔门外，肉身塔从此不再开门。
6. 锚定图不可随意改动；改需解锁（见 character-reference-lock 的追加解锁项机制）。
7. 禁止香客手中持香：手持香/线香仅出现在寺庙内礼佛上香场景；正常走路、上山朝圣途中持香不符合逻辑，画面中香客手中不得出现香。
