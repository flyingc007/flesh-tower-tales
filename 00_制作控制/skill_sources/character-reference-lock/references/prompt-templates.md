# Prompt Templates（角色参考锁定 - 配套模板与指令）

> 本文件是 character-reference-lock 的配套参考。协议激活后，生图时必须读取本文件并按其中模板拼接提示词。

## 1. 标准提示词模板（自动拼接）

协议激活后，将以下契约文本拼接到正向提示词最前部；`{可变内容}` 为用户明确写出的可变项，无则填【无】：

```
【角色锁定协议已激活】以用户上传三视图角色参考图为基准源。
冻结锁定，禁止修改：容貌、五官、肤色、毛发、体表纹理、服饰款式配色材质、道具器械、物种形体特征，全部禁止重设计或魔改。
仅允许修改：{可变内容}
禁止：自主优化面部、改动服饰道具、新增装饰、替换角色特征。
渲染、画质、风格描述放其后。
```

### 负面提示词自动追加段

拼接为负面词，恒常生效：

```
修改面部，换脸，改动五官，更改发型，修改服装样式，改动道具，增减配饰，修改体表纹理，角色魔改，角色重设计
```

## 2. 内置正向模板（协议激活时优先于用户原文使用）

- 参考图唯一性：以参考三视图为唯一角色基准，严格锁定脸型五官、服饰、道具、配色材质不变。
- 语义：**强制锁定、禁止修改、不得改动、仅允许改动 XX**（强指令）；避免"保持差不多、尽量像、风格一致"等弱指令。

## 3. 用户侧开关指令（控制协议启停，不改整套规则）

- `启用角色锁定协议` — 开启全部规则。
- `解除角色锁定协议` — 关闭本协议，恢复正常自由生图。
- `追加解锁项：XXX` — 在冻结集里单独放开某一项（例：追加解锁项：衣服颜色）。

> 例：用户说「启用角色锁定协议，追加解锁项：衣服颜色；只改背景成山林」→ 仅【衣服颜色、背景】可动，其余容貌、五官、道具依旧冻结。

## 4. 应答话术（异常场景）

1. 用户试图修改冻结域且未追加解锁：
   > 当前角色锁定协议已生效，该属性属于默认锁定范围，不能修改。如需改动该角色特征，请发送【追加解锁项：xxx】单独放开，或发送【解除角色锁定协议】关闭锁定规则。
2. 用户只发参考图、未写可变内容：
   > 角色锁定协议已生效，无指定可修改项目，将原样复刻参考角色。如需调整姿势/场景/灯光，请补充写明要修改的内容。
3. 用户使用模糊话术（优化/微调/变好看）：
   > 这类描述无法作为合法修改项，角色锁定保持不变。请明确写出你想要修改的具体项目。

## 5. 参考相似度参数建议（生图工具支持时）

- 参考相似度 / 结构保持拉高到 **0.75 ~ 0.85**。
- 太高（0.9+）：光影姿势被锁死，无法做用户指定变更。
- 太低（0.6 以下）：参考图权重变弱，文字优先，疯狂魔改。

## 6. 提升锁定力的输入建议（向用户说明）

- 优先使用**三视图/turnaround sheet**作为参考图（正/侧/背信息完整，AI 无从脑补背面、侧面、尾巴）。
- 单张正面图也可用，但锁定力较弱，提示用户可补侧背面。
- 固定特征可单独整理一份角色档案，随提示词反复粘贴做双保险（可选，非必需）。
