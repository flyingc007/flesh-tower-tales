# AI 视频项目 · Skill 搭建规范模板

> 本文件是一份**可复制的项目模板**。把 `{{占位符}}` 替换为你自己的项目信息即可套用。
> 它把肉身塔项目验证过的机制抽象为三层结构，任何 AI 视频项目（分镜逐镜头生成）都能照此搭建。
> 用途：给下一个项目做参考，避免每次从零设计"资产查找 + 角色锁定"机制。

---

## 〇、这份规范在解决什么

AI 视频项目最常见的三个失效点：
1. **生成时不知依据哪份文档** → 靠 AI 记忆取材，设定漂移。
2. **不知去哪找角色/场景资产** → 素材散落在会话里，不集中可检索。
3. **角色被魔改、形态混用** → 锚定图被当成风格摆设，AI 脑补重绘。

本规范用三层结构 + 强制前置步骤解决以上问题。

---

## 一、三层结构总览

| 层 | 内容 | 存放位置 | Git 归属 |
|----|------|---------|---------|
| ① 通用规则层 | 角色锁定协议（跨项目共享，不绑项目） | 通用 skill 仓库 / `.user_skills` | 独立仓库 |
| ② 项目总控层 | 项目总纲（设定基准+资产清单+红线+形态区分）+ 项目总控 Skill | 随项目目录 | 随项目仓库 |
| ③ 目录与部署约定 | 固定命名规范 + 部署到 `.user_skills` | 项目目录 | 随项目仓库 |

> 原则：**一份源、多处使用**。Git 仓库放源，`.user_skills` 放运行时部署副本。

---

## 二、① 通用规则层（只建一次，跨项目共享）

### 角色参考锁定协议（必建）

通用 Skill：`character-reference-lock`
- 作用：用户附带角色参考图时，默认冻结角色全部识别属性（容貌/肤色/毛发/体表纹理/服饰/道具/物种形体），仅允许修改用户显式写出的项目。
- 定位：与具体项目无关，任何三视图角色可套用。
- 关键：触发词用泛化词，不写死任何项目角色名。

**此层只需搭建一次，新项目直接复用，不再重写。**

## 四、② 项目总控 Skill 模板（每项目一份）

> 在 `.user_skills` 新建 `<项目英文名>-producer`，写入以下结构（替换占位符）。

```markdown
---
name: {{project_en}}-producer
description: 《{{项目名}}》项目的制作总控。当任何涉及该项目的内容生成（分镜生成、图像生成、视频生成、资产取用、角色复用）时使用，负责"读项目总纲 → 定位资产 → 应用角色锁定 → 产出"的整条链路。触发词：{{项目名}}、{{各角色名}}、{{各场景名}}、{{关键事件词}}、分镜，或该项目的任何角色/场景名称。
---

# {{项目名}} · 制作总控

## 触发条件
任何与《{{项目名}}》相关的内容生成任务均触发。

## 触发保障（重要）
本 skill 依靠 description 关键词触发。执行时提醒用户：生成请求尽量带项目/角色/场景关键词。若表述完全不含关键词，主动补问是否属于本项目，确认后仍走完整链路，避免退回凭记忆取材。

## 强制前置：读项目总纲（唯一设定基准）
第一步必须完整读取：`{{项目绝对路径}}\00_项目总纲.md`

## 核心流程
### 第 1 步：读总纲
完整读取 `00_项目总纲.md`，冲突以总纲为准。

### 第 2 步：定位资产
按总纲清单，从 `{{项目绝对路径}}\03_图像资产\` 定位锚定图，缺失如实报告。

### 第 3 步：应用角色锁定协议
涉及角色复用/图生/图生视频时，必须读取并应用通用 skill `character-reference-lock`（路径见下方部署约定），按其契约锁定角色、拼接强约束提示词与负面词。

### 第 4 步：执行角色形态区分
按总纲第五节严格执行，两种形态不可混用。

## 红线清单（生成时逐项检查）
{{从总纲第二节复制红线，逐条列出}}

## 输出与交付
- 图像/视频按用户指定方式交付。
- 涉及新资产或设定调整，提示更新 `00_项目总纲.md` 版本号。

## 协作提示
- 资产索引在**本地目录**（03_图像资产），资产查找一律以总纲清单 + 本地目录为准。
```

## 六、部署与 Git 约定

### 部署到运行环境（让 skill 生效）
- 源版本放 Git 仓库，运行时需**部署副本**到豆包 skill 根：
  `...\.doubao\agent_mode\workspace\.user_skills\<skill名>\`
- 改动通用层或总控后 → 覆盖部署到 `.user_skills` 生效。

### 路径参数化（上传 GitHub 前必做）
- Skill 正文**不得写死绝对路径**。用占位符 `{{项目绝对路径}}` 等，部署时替换成本机路径。
- 通用层不得含任何项目特定信息。

### Git 归属
- ① 通用层 → **独立通用仓库**，可公开分享。
- ② 项目层 → **随项目仓库**（含项目红线等私有设定，是否公开自行决定）。

- [ ] 总控 Skill 正文含：读总纲强制步骤、定位资产、引用通用锁定、形态区分、红线
