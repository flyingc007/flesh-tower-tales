# 谛听神兽参考资产生成（Turnsheet）

## 一、用途
为《肉身塔传说》项目批量生成谛听（九不象）神兽的分部位建模参考资产（Turnaround Sheet），产出可直接用于 Houdini / UE / ZBrush 参考的写实照片级素材。

## 二、铁律（最高优先级，不可违反）
1. **三视图必须合入同一张图**，禁止分开发出三个独立文件。
2. **质感必须电影级真实**，禁止卡通、手绘、插画、工笔、游戏渲染感。
3. **毛发必须是真实毛发质感**，禁止毛绒玩具感、塑料感、油光贴图感。
4. **鳞片必须真实**：有明暗过渡、边缘高光、材质反光层次，禁止平涂色块。
5. **每张图只含一个部位**，禁止在资产图里混入背景场景、经案、佛像、云雾、文字水印。

## 三、构图规范（每一张资产图都必须遵守）
### 画面布局
- **单张横向画布，横向排布三个视图**：正视图 + 45°斜侧视图 + 纯侧视图，三格并排。
- 三个视图内主体**等高对齐**，底部基准线一致，方便建模时拉辅助线比对。
- 每个视图之间留均匀间隙，不重叠、不裁切主体。

### 视图角度定义
- **正视图**：正对主体（头部为纯正面；腿部为纯正面朝向镜头）。
- **45°斜侧视图**：以垂直轴旋转约45°，能同时看到正面与侧面的结构关系。
- **纯侧视图**：正侧面90°，展示厚度、纵深与侧向轮廓。

### 光影
- 三个视图**光源统一**：固定在前侧上方，方向一致。
- 柔和主光 + 环境补光，皮肤/毛发/鳞片有清晰明暗与高光。
- 禁止三个视图各自打光、方向不一致。

### 背景
- **纯白背景**，干净无杂物，无地面阴影以外的多余元素。
- 主体完整入画，边缘清晰，不裁断肢体。

## 四、质感规范（电影级真实）
### 通用
- 写实摄影质感，高细节，商业摄影级清晰度，8K。
- 材质要有真实反射、次表面透光感，禁止塑料感。

### 毛发（虎头、狮尾、麒麟腿关节毛）
- 单根发丝可见，有毛流方向与分层，随光影变化。
- 禁止卡通一撮撮、贴图贴片、顺滑塑料毛。

### 鳞片（龙身、麒麟腿）
- 鳞片排列有自然错位，边缘有高光描边，有受光面和背光面。
- 禁止平涂色块、统一平面反光。

### 蹄 / 角 / 爪
- 麒麟足：两瓣牛偶蹄，蹄壳有真实质地与反光，无尖爪。
- 独角：骨质、有年轮纹理，顶部微光泽。

## 五、部位资产清单与专用要求

| 部位 | 视图要求 | 专属要点 |
|------|----------|----------|
| 虎头（基准） | 正面+45°侧+纯侧 | 以已生成的虎头三视图为**风格/比例基准**，虎纹、白口鼻、竖耳统一 |
| 麒麟四肢 | 正面+45°侧+纯侧 | 完整结构：**大腿→小腿→跗部→蹄壳**，两瓣牛偶蹄，直立瑞兽腿，无狼爪 |
| 龙身躯干 | 俯视+45°侧+纯侧 | 长躯、鳞甲、背脊线、腹侧层次 |
| 狮尾 | 侧面+45°+连接臀部视角 | 尾椎+蓬松真实尾毛 |
| 独角+额头衔接段 | 正面+45°侧+纯侧 | 骨质角+与虎头衔接过渡 |
| 颈肩过渡段 | 正面+45°侧+纯侧 | 虎头皮毛→龙鳞渐变衔接 |
| 最终汇总 | 完整谛听全身三视图 | 九不象全要素，比例统一 |

### 虎头基准（写死锚点）
- 暖橙底色、黑色虎纹，口鼻周围白色毛发。
- 耳朵厚实圆润、竖直竖起（不耷拉）。
- 眼睛淡黄绿色，鼻头粉色，浓密胡须，毛发蓬松真实。
- 参考已确认的虎头三视图，后续所有部位虎纹与头部比例以此为准。

### 麒麟四肢完整结构（写死锚点）
- 自上而下必须包含四个结构段：**大腿 → 小腿 → 跗部 → 蹄壳**。
- 大腿：粗壮，肌肉/毛发衔接身体，关节毛真实。
- 小腿：收细，鳞片与短毛过渡。
- 跗部：关节结构清晰，是承重与屈伸关键点。
- 蹄壳：**两瓣牛偶蹄**，有真实质地与反光，无尖爪、无狼爪。
- 直立瑞兽腿型，承重姿态，非犬科爪行足。

## 六、提示词写作规范（每次生成必须遵循）
- 每张资产图写**正向提示词 + 反向提示词**。
- 正向词固定开头：`真实摄影质感，写实照片，电影级，白底影棚，光源前侧上方`
- 正向词必须写明：`同一主体，横向三视图：正视图、45°斜侧视图、纯侧视图，三视图等高对齐，斑纹与鳞片纹理完全统一`
- 反向词固定包含：`卡通，手绘，插画，工笔，游戏渲染，塑料感，玩具毛，平涂鳞片，复杂背景，文字水印，多只主体，比例错乱`

## 七、验收标准（生成后自检）
- [ ] 三视图是否在同一张图内且横向排布
- [ ] 三视图是否等高对齐
- [ ] 材质是否电影级真实（毛发见丝、鳞片有光影层次）
- [ ] 是否纯白背景、无多余杂物
- [ ] 是否只含目标部位，比例是否协调
- [ ] 麒麟四肢是否含 大腿→小腿→跗部→蹄壳 四段完整结构
- [ ] 虎头是否与基准三视图斑纹、比例一致
