# 谛听 · 颈肩过渡段（拼接段）提示词

## 设计逻辑（三段式渐变）
虎毛 → 覆羽 → 鳞片，平滑过渡无硬边界。加入禽类覆羽作为中间层，解决虎头皮毛与龙鳞材质突变的拼接问题，同时增加"九不象"的物种拼接丰富度。

---

## 正向提示词

```
真实摄影质感，写实照片，电影级，白底影棚，光源前侧上方。神兽颈肩过渡段部位资产图，横向三视图：正视图、45°斜侧视图、纯侧视图，三视图等高对齐，纹理完全统一。主体为从喉部到肩胸的一段颈柱，不出现完整面部和四肢。

从上到下三段式渐变：
上段（连接虎头）：暖橙黄色短毛，带黑色虎纹，下颌白色绒毛，自然虎头皮毛质感。
中段（颈肩过渡核心）：虎毛逐渐变成一层一层叠瓦状排列的禽类覆羽，类似猛禽颈羽，羽毛从暖棕褐渐染为铜青灰绿色，羽片有清晰羽轴和毛缘，羽片边缘微微翘起，背脊处羽毛拉长为竖立的冠羽。
下段（连接龙身）：覆羽越来越短越来越圆，逐渐过渡为带金色描边的青灰蓝绿色圆形鳞片，鳞片排列整齐，背脊处的冠羽过渡为一排金色棘刺状鬃脊，腹侧为米白色大块鳞甲。

三段之间平滑渐变无硬边界，材质真实：毛发根根分明、羽毛有羽片纹理和透光感、鳞片有金边高光和次表面质感。纯白背景，无杂物无文字水印。
```

## 反向提示词

```
卡通，手绘，插画，工笔，游戏渲染，塑料感，玩具毛，平涂色块，复杂背景，文字水印，多只主体，比例错乱，完整头部，脸，眼睛，四肢，硬边界突变
```

## 全身拼接时各部位衔接口径

| 衔接位置 | 材质过渡 | 颜色过渡 | 背脊线 |
|----------|----------|----------|--------|
| 虎头 → 颈上段 | 虎毛直接延续 | 橙黄虎纹 → 纯橙毛 | 虎毛后脑处开始拉长 |
| 颈上段 → 颈中段 | 虎毛 → 叠瓦覆羽 | 暖棕褐渐染铜青 | 拉长为冠羽 |
| 颈中段 → 肩下段 | 覆羽变短变圆 → 鳞片 | 铜青绿 → 青灰蓝绿 | 冠羽 → 金色棘刺 |
| 肩下段 → 龙身躯干 | 鳞片无缝衔接 | 青灰金边一致 | 金棘连续延伸 |
| 躯干 → 麒麟四肢 | 鳞片 → 短毛/关节毛 | 青灰 → 橙棕关节毛 | 金棘在腰侧结束 |
| 躯干 → 狮尾 | 鳞片 → 尾椎骨节 | 青灰 → 棕褐尾毛 | 金棘沿尾椎延续 |
